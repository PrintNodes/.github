# 🔌 PrintNode

PrintNode is a **cloud print API** paired with **local agents**. Send jobs from an app and the agent routes them to an attached printer, including devices behind a firewall.

## ✨ Key Features

- 🌐 **REST print API**
- 🖥️ **Local agent** for private networks
- 🧾 **Raw ESC/POS support**
- 📑 **PDF and office documents**
- 📊 **Job status tracking**
- 🖨️ **Multi-printer routing**
- 🔐 **API key scopes**
- 📄 **Print options per job**

## 🚀 Why Choose PrintNode?

Firewalls block inbound printing, so the agent dials out and keeps the printer reachable. The API covers raw receipts and office documents through the same endpoint.

Job status makes failures visible to the calling app instead of silent.

## 🎮 Why Use It?

- **Print from web apps**
- **Reach printers behind NAT**
- **Send receipts** as raw data
- **Track job status**
- **Route to several devices**

## 🧩 Quick Start

1. Create an API key.
2. Install the agent on a local machine.
3. Attach and register the printer.
4. Send a test job from the API.
5. Check the job status.
